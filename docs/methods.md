# Research Methods

1. **Record the information.** Capture the original source, publication and observation times, and the audience that could have seen it. Separate the source's claims from independently observed outcomes.
2. **Identify the narrative.** Write one sentence linking the claimed mechanism to an expected outcome. Record competing interpretations that use the same information.
3. **Define the audience and baseline.** Record prior expectations, the observation window, and how exposure will be measured.
4. **Build a testable narrative.** State the relevant evidence, explain the mechanism in the audience's terms, and make a prediction with a deadline and a measurable outcome.
5. **Observe decisions.** Track attention, expectation change, resource commitments, and behavior using separately defined measures. Where feasible, compare with a similar unexposed audience or run a randomized test.
6. **Review the claim.** Check timing, confounders, and competing explanations. Record which observations support each link and which remain unresolved.

A case record contains the source, audience, baseline, narrative claim, prediction, observations, alternative explanations, and current conclusion. Preserve the original prediction so it can be compared with the outcome.
